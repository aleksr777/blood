# Общие стили интерфейса

- `tokens.css` — палитра, размеры, скругления, тени и длительности переходов. Семантические цвета компонентов крови и резуса заданы отдельно от цветов обычных действий.
- `controls.css` — единое оформление нативных полей, текстовых областей, флажков и радиокнопок.
- `ui.css` — переиспользуемые кнопки, сетки форм, группы полей, подписи переключателей, карточки, списки и сообщения.
- `ui.ts` — общие классы для JSX: `ui.primaryButton`, `ui.warningNotice` и другие варианты.

Общие стили подключаются один раз в `main.tsx`. Нативные элементы и UI-классы находятся в слое `blood-ui`, поэтому локальные стили компонентов могут менять их размеры и расположение без `!important`. В JSX импортируйте `ui` из `styles/ui`. В CSS Modules используйте композицию глобальных классов с префиксом `ui-`:

```css
.apply {
  composes: ui-button ui-primary-button from global;
}

.group {
  composes: ui-fieldset from global;
}
```

Варианты действий: `primaryButton`, `secondaryButton`, `successButton`, `dangerButton`, `dangerPrimaryButton`. Размеры можно изменить классами `compactButton` и `toolbarButton`. Иконки используют `iconButton`, `successIcon` или `dangerIcon`.

`aria-disabled` меняет только внешний вид: кнопки сохранения и печати протокола должны продолжать принимать нажатия для показа предупреждения. Нативный `disabled` блокирует действия во время загрузки.

Печатные страницы сохраняют собственные размеры, шрифты и чёрно-белые цвета. Общие стили интерфейса не следует применять к таблицам и строкам печатных бланков.
