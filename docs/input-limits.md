# Ограничения ввода

| Поле | Диапазон или длина |
| --- | --- |
| Частота пульса | Целое число от 1 до 999 |
| Температура | От 20 до 50 °C, дробные значения допустимы |
| Диурез | От 0 до 9999 мл, дробные значения допустимы |
| Однострочный текст | По умолчанию 255 символов |
| Многострочный текст | По умолчанию 2000 символов |

Диапазоны наблюдения действуют для всех трёх временных промежутков. Общий `BoundedNumberInput` проверяет ввод и вставку, поддерживает очистку и не передаёт наружу числа вне диапазона. Для набора числа с ненулевой нижней границей можно временно ввести его начало: например, `2` перед `25`. Если уйти из такого поля до завершения ввода, возвращается последнее принятое значение.

Текстовые поля используют `FormInput` и `FormTextarea` из `src/components/form-input/form-input.tsx`. Явный `maxLength` имеет приоритет над общим лимитом: номер гемакона сохраняет прежний лимит 16 символов с учётом пробелов. Даты, время, числовые поля, переключатели и списки не получают текстовое ограничение.

При открытии существующие длинные тексты и прежние числовые значения не обрезаются и автоматически не меняются. Нередактируемые сведения о предыдущих трансфузиях, сформированные из архива, не входят в лимит свободного текста анамнеза.
